# FirmPulse 1.0.0

Samsung test and released firmware, in one place. Developed by Haroon.

- Clean first launch; Samsung phones can prefill their own model. Region/CSC remains editable.
- Phone-based theme by default, with optional Light and Dark themes.
- Older test and beta entries have clear age notices when the available evidence supports them.
- S-series checks clearly announce that support is being improved and results may not be fully accurate yet.
- Blue test cards, mint released tags, softer glow and a floating frosted navigation bar.
- Short spring transitions, subtle press feedback, Reduce motion and Glass effects controls.
- Saved devices, local hidden-name matching, released history, optional alerts and exports.
- Haroon’s profile and GitHub/Website/LinkedIn links at the top of Settings, with the repository link at the bottom.
- Optional one-time star prompt five seconds after the first completed check with available data.
- Share buttons on test/beta and latest-available cards export a branded image with full builds, supplied dates and relevant warnings.

**Known limitations:** Newest hidden test names cannot always be recovered, particularly on S-series devices. Test entries do not establish public beta availability or rollout dates. Android decides background-check timing. Glass blur requires Android 12+; Android 9–11 use a tinted surface. Physical-phone performance and model coverage remain to be checked and reported.

Android 9+ required. No account, ads or analytics.

If upgrading from an earlier development build, export your saved devices before uninstalling it. Install this release and import the backup. Those development builds use a different signing certificate.

Source and contributions: https://github.com/haroon-ai1/FirmPulse
